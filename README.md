### 새 태스크 생성
- [x] 새 태스크를 생성할 때 X를 누르면 이전 화면으로 돌아간다.
- [x] 새 태스크를 만들다가 취소를 누르면 생성을 취소한다.
- [x] 새 태스크를 생성한다.
- [x] 새로운 태스크가 생성되면 아래에 "새로운 태스크가 추가되었습니다" 라고 적힌 알림창을 띄운다.
