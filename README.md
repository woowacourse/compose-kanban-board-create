# compose-kanban-board-create

## 🚀 2단계 - 칸반 보드 생성(보드)

### 구현할 기능 목록

- [ ] 칸반 보드 기본 화면
  - [ ] 상태 컬럼(To-Do, In Progress, Done)을 화면에 표시한다.
  - [ ] 각 상태 컬럼에 해당 상태의 태스크 카드 목록을 표시한다.

- [ ] 새 태스크 생성 모달
  - [ ] "+ 새 태스크 생성" 버튼을 클릭하면 모달을 연다.
  - [ ] 모달 외부 클릭 또는 닫기 클릭 시 모달을 닫는다.
  - [ ] 태스크 생성 완료 시 모달을 닫고 보드에 반영한다.

- [ ] 상태별 태스크 트래킹
  - [ ] 전체 태스크를 상태별로 분류한다.
  - [ ] 상태별 태스크 개수를 계산한다.
  - [ ] 각 상태 헤더에 태스크 개수를 노출한다.

- [ ] 완료 비율 계산
  - [ ] 전체 태스크 수를 계산한다.
  - [ ] 완료(Done) 태스크 수를 계산한다.
  - [ ] 완료 비율(Done / Total)을 계산한다.
  - [ ] 완료 비율을 UI에 표시한다.

- [ ] 태스크 생성 완료 시 Snackbar 생성
    - [ ] 태스크 생성 완료 시 "태스크가 생성되었습니다." 메시지를 Snackbar로 표시한다.
    - [ ] Snackbar는 일정 시간 후 자동으로 사라지도록 한다.
